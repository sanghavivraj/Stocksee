# StockSee Frontend

This is the React + Vite frontend for StockSee.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables:
   Copy `.env.example` to `.env` and adjust the variables if needed.
   ```bash
   cp .env.example .env
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Available Pages
- **Dashboard**: Live exchange overview, morning macro brief, and market pulse.
- **My Watchlist**: Client-side monitoring tool to track Indian equities with real-time TradingView charts (no auth required).
- **Alerts**: Create and configure custom price and percentage move alerts.
- **Ask StockSee**: AI market and financial assistant supporting vernacular interactions.
- **Settings**: Language preferences (English, Hindi, Gujarati) and user account info.
